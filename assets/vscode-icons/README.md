# Javafy File Icons

A dedicated Visual Studio Code icon theme for Javafy and modern TypeScript projects.

## Try it locally

1. Open `assets/vscode-icons` as the extension folder in VS Code.
2. Press **F5** to launch the Extension Development Host.
3. Run **Preferences: File Icon Theme**.
4. Select **Javafy File Icons**.

To package it, install VS Code Extension Manager and run `vsce package` from this directory.

## Native Javafy formats

- `.jfy` — pages and routes
- `.jfc` — reusable UI components
- `.jfs` — server-side services
- `.jfa` — API endpoints

Includes TypeScript, TSX, JavaScript, JSON, CSS, Markdown, HTML, SVG, YAML and folder icons.
