# Security Policy

## Supported versions

Security fixes are applied to the latest stable Javafy release. During the 1.0.0
release-candidate period, security fixes are also considered for the active
1.0.0 development branch.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue.
Use GitHub's private vulnerability reporting feature for this repository.
Include the affected Javafy version, Node.js version, reproduction steps, and
the impact you believe an attacker could achieve.

Do not include real user data, credentials, or production secrets in reports.
We will acknowledge reports as soon as reasonably possible and coordinate a
fix and disclosure timeline with the reporter.
