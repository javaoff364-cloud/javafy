# Javafy

One dependency for a modern React + TypeScript fullstack app.

```sh
npm install javafy
npx javafy create my-app
cd my-app
npm install
npm run dev
```

Javafy includes its CLI, compiler, router, server runtime, and Vercel adapter in one npm package. The `@javafy/*` workspace packages are internal development units, not separate application dependencies.

Native source files: `.jf` (TypeScript), `.jfx` (TypeScript + JSX), `.jfc` (components), `.jfa` (API routes), and `.jfs` (server modules). Standard `.ts` and `.tsx` files remain supported.

Documentation: https://github.com/javaoff364-cloud/javafy#readme
